# Local content workspace

This directory is intentionally present without media files in the public repository.

- `source-images/` contains local source photographs and is ignored by Git.
- `publish/` contains the generated Cloudflare R2 payload and is ignored by Git.
- `editorial/Редакционная-очередь.xlsx` is the local review queue for location candidates, preliminary story ideas, card drafts, user decisions, and comments. Unapproved content stays here and must not be exported to the catalog.

See `publisher/README.md` and `docs/CONTENT-PUBLISHING.md` for the local workflow.
